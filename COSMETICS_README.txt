CUSTOM COSMETICS SYSTEM

Folder automatically created:
.minecraft/custom_cosmetic/

Supported:
- capes
- hats
- wings
- masks

Example:
custom_cosmetic/capes/mycape.png

Features added:
- equip system
- remove all cosmetics
- cosmetic registry
- dynamic PNG loading
- future cosmetic expansion base

You still need:
- actual cape renderer
- GUI buttons
- preview renderer
- texture upload system

Build:
./gradlew build
